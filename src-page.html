Embedded Web Editor

Make a game right here, in one tab.

The full official Godot Engine editor — scene tree, script editor, inspector, the project manager and the game runner — compiled to WebAssembly and running right here. It starts on its own: no start button, nothing to install.

↗Open in new tab

The very first run downloads the engine (~92 MB) and caches it in this browser, so later loads start almost instantly. Projects you create are saved in this browser, tied to this page.

Compatibility check

    Good to know

    • Works on phones and tablets too — open the ☰ menu for controls, use Keys for the on-screen keyboard, rotate to landscape for more room.
    • The engine runs on shared-memory worker threads, so it needs a cross-origin-isolated page (this one is).
    • Press F5 in the editor to run your game — a Game tab appears next to Editor.
    • Intended for learning and prototyping; export from the native editor for real projects.
    • Preload an existing project as a ZIP from the project manager's Import dialog.
